# Krstenica Docs

Ovaj direktorijum je tehnicka dokumentacija za razvoj, odrzavanje i buduci AI-assisted rad na projektu.

## Sadrzaj

- [PROJECT_OVERVIEW.md](PROJECT_OVERVIEW.md) - kratak opis aplikacije, domena i glavnih modula.
- [ARCHITECTURE.md](ARCHITECTURE.md) - slojevi aplikacije i tok zahteva kroz Gin, HTMX, servis i repository.
- [DEVELOPMENT.md](DEVELOPMENT.md) - lokalno okruzenje, konfiguracija, build i testiranje.
- [API_AND_UI.md](API_AND_UI.md) - API rute, GUI rute, HTMX obrasci i prava pristupa.
- [DEPLOYMENT.md](DEPLOYMENT.md) - Docker, konfiguracija servera i operativni deployment tok.
- [AI_AND_AUTOMATION.md](AI_AND_AUTOMATION.md) - pravila za AI agente i buduce pomocne skripte.

## Napomene

- Korisnicka uputstva ostaju u `USER_GUIDE.md`, `VIZUELNO_UPUTSTVO.html`, `VIZUELNO_UPUTSTVO.pdf` i `/ui/uputstvo`.
- `SESSION.md` je operativni handoff i mora se azurirati pre kraja svake sesije rada.
- Ne upisivati lozinke, tokene, privatne kljuceve ili produkcione tajne u `docs/`.
